TransitCloud is a cloud-hosted web application for searching bus routes, selecting seats, and booking tickets online, developed as part of the CodSoft Cloud Computing Internship (Task 3).

🚀 Key Features
Route Discovery & Filtering: Search schedules by origin city, destination, and travel date with instant bus service filtering.

Interactive 2x2 Seat Layout: Visual seat matrix indicating Available, Selected, Booked, Held, and Ladies-only seats.

Concurrency & Double-Booking Protection: Real-time seat reservation logic preventing race conditions and double bookings.

Passenger Verification & Checkout: Boarding/drop-off point selection, transit insurance toggle, and checkout modal supporting UPI, Cards, Net Banking, and Wallets.

Digital Boarding Pass & PNR Management: Generates confirmed tickets with unique PNR, verified QR/barcode, JSON export, and instant cancellation via "My Bookings".

🛠️ Tech Stack
Frontend: React, Tailwind CSS, Lucide React Icons

Database & State: ACID transactional write simulation / Persistent cloud database architecture

Design System: Minimalist white UI with emerald transit accents
